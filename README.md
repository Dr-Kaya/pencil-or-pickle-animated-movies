# Pencil or Pickle? — Animated chapter adaptations

[Watch all six chapters online](https://dr-kaya.github.io/pencil-or-pickle-animated-movies/)

These are the revised illustrated storybook adaptations, with narration, character voices, sound effects, 232 story-timed shots, and animated learning examples. Four short generated character clips each appear once in the matching story moment. They are not continuous full-body character animation.

The `assets` directory holds one archive per chapter. Publishing extracts the original MP4s, poster images, and English captions without re-encoding them, and builds a portable download containing all six movies.

Text: The DCoaD Literacies Lab and Friends. Book copyright © 2026 Amy Hutchison, Brittany Adams, Kristie Gutierrez, and Erdogan Kaya. Illustrations and book design © 2026 Rebeca J. Pintos. Voices and sounds generated with ElevenLabs; adult voices perform the student roles. Original rights remain with their holders.

This is an independent movie website. Run `python3 scripts/build_site.py _site` to build it. GitHub Pages publishes the `_site` folder through the included workflow. No API keys or external media services are required.
